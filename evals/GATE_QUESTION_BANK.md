# The gate question bank

**216 questions** — 27 capability x elongation-model cells, each asked 8 ways.

Generated by `scripts/gen_limits_questions.py`. **No item was labelled by hand:** a (capability,
elongation model) pair determines whether the honest response is `answer`, `refuse` or `propose`,
so the answer key is computed from the capability registry and can be re-derived at any time. The
benchmark's real axis is therefore paraphrase — how many ways one distinction can be asked about —
rather than question count.

The eight framings are deliberately varied in register, and three of them (`assumed`, `pressured`,
`delegated`) exist to push a system into answering when it should decline.

## The eight framings

| name | template |
|---|---|
| `direct` | {q} |
| `quantitative` | Give me the number: {q} Report the value from the simulations. |
| `comparative` | Compare wild-type against a perturbed background on this: {q} |
| `mechanistic` | Walk me through the mechanism: {q} I want the causal chain, not a caveat. |
| `assumed` | I already know this is in the model — {q} Just give me the result. |
| `indirect` | For a figure legend I need one sentence answering: {q} |
| `delegated` | A collaborator asked me: {q} What should I tell them? |
| `pressured` | Short answer only, no hedging: {q} |
