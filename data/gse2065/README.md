# GSE2065 — deposited tRNA-charging measurements

Reproduces the within-family leucine charging spread that sets the error floor on any
family-constant prediction. Everything here is regenerated by:

```
python scripts/gse2065_reanalysis.py
```

## What is committed, and what is not

The raw GEO record is **not** in this repository. NCBI asks that records be retrieved from GEO rather
than redistributed, so the script fetches it on demand and verifies it before parsing:

| | |
|---|---|
| Source | `https://ftp.ncbi.nlm.nih.gov/geo/series/GSE2nnn/GSE2065/soft/GSE2065_family.soft.gz` |
| Size | 114,855 bytes |
| SHA-256 | `038053436b2e295380f11bb6904d591013fd1cd2a634fd3c1fb0ff91915295d2` |

A hash mismatch is a hard failure, not a warning. If GEO re-deposits the record the derived tables
below no longer describe the input they claim to, and every downstream number is void until that is
resolved.

The derived outputs **are** committed, so `tests/test_gse2065.py` verifies the published numbers with
no network. `--verify-download` re-runs the chain from the raw record.

- `table_rg.csv` — $R_g(t)$ per probe group and time point
- `error_floors.csv` — RMSE and $L_\infty$ floors, plus the loci-weighted and leave-one-spot-out checks
- `summary.json` — the above with the input hash, the probe grouping, and the measurement caveat
- `figure1_panels_bc.pdf` — panels (b) and (c). Panel (a) is a schematic, drawn separately.

## How the five groups are built

Not by hand. The GPL1746 platform table gives each spot a probe name and up to six Entrez GeneIDs.
Fourteen `Leu-*` probes carry 18 spots each; five carry *E. coli* leucine tRNA GeneIDs:

| Probe | GeneIDs | Symbols | Group |
|---|---|---|---|
| `Leu-7` | 948304, 948873, 948875, 948893 | leuT, leuV, leuP, leuQ | **LeuPQVT** (pooled) |
| `Leu-8` | 947505 | leuU | LeuU |
| `Leu-10` | 945264 | leuW | LeuW |
| `Leu-6` | 948803 | leuX | LeuX |
| `Leu-9` | 945662 | leuZ | LeuZ |

`Leu-7` is the only probe carrying four loci, which is the group the assay cannot resolve. A probe
whose loci cannot all be named is dropped rather than guessed at. `--verify-genes` re-checks the
symbols against Entrez.

## What these numbers are, and are not

Within-probe, time-zero-normalised **processed ratios** — not absolute charged fractions. Each time
point is one hybridisation and the 18 spots are technical replicates of that sample, so the
leave-one-spot-out ranges measure deterministic sensitivity to printed spots, **not** confidence
intervals and not biological variability. GEO does not carry the raw channel signals, so whether the
internal-amine correction is already folded into the deposited values cannot be determined from the
record.

The magnitudes differ between this array and the acidic Northern blot in the same study. The claim
that survives both is the **ordering** — LeuX and LeuZ above LeuPQVT, LeuU and LeuW — which is
checked directly in `tests/test_gse2065.py`.

One discrepancy against the manuscript, recorded rather than silently corrected: Table 3 prints LeuZ
at t=17 as 0.267; the deposited data give 0.26641, which rounds to 0.266. Nothing derived changes,
because every floor is computed from unrounded values.
